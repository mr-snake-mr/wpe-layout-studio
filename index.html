      The problem

      Factory floor space is scarce. Planners must fit machines, robots, fixtures, inspection points and material storage into a fixed area while keeping material flow short, access safe and every clearance rule intact. Today that means manual iteration after iteration.

      WPE Layout Studio turns the brief into an executable rule set: it derives the resource count from the line rate, generates alternative shopfloor arrangements, scores each one against the clearances and keeps the layout with the shortest material flow that is fully compliant.

      How JPH drives the layout

      cycle time = 3600 ÷ JPH
      resources ≈ work time ÷ cycle time

      At 60 JPH a job must leave every 60 s. A robot work content of 150 s therefore needs 3 robots; 280 s needs 5. Those counts are the input to the planner, so the drawing always matches the production target instead of a guess.

      Rule set enforced

        Pipeline

        1. 1
          Input

          Hall footprint, JPH, activity times, resource counts, clearance thresholds.

        2. 2
          Plan

          Cycle time → robots; modules are built in process sequence with their own fenced cells and controller rows.

        3. 3
          Generate

          Modules are packed into serpentine rows across a range of row / module gaps — every alternative is a real candidate.

        4. 4
          Verify

          The rule engine recomputes all clearances from geometry, floods the walkway grid for continuity and rejects violations.

        5. 5
          Deliver

          Best compliant arrangement rendered on canvas, exported as PNG / DXF / JSON with a per-rule compliance record.
